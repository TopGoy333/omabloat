omabloat

A read-only bloat detector for Omarchy (and plain Arch). Make Omarchy accessible to the average PC user.

The main file

find-omarchy-bloat.sh is the heart of this repo. It detects bloat and reports it. It does not remove anything, so it is safe to run at any time.

Quick start

chmod +x find-omarchy-bloat.sh
./find-omarchy-bloat.sh              # full read-only report
./find-omarchy-bloat.sh --space-only # adds sizes for the candidates
./find-omarchy-bloat.sh --verbose    # deeper home-directory scan

What the report shows

  • Preinstalled bloat candidates: office suites, media editors, Chromium web-app wrappers, optional services like Docker.
  • Web-app launchers in ~/.local/share/applications (Discord, YouTube, …).
  • The biggest folders in your home directory.
  • Orphaned packages (pacman -Qdtq) — installed but no longer required.
  • Graphical utilities you may not need if you live in the terminal.
  • With --space-only: how much disk each candidate uses.
  • Recommendations — printed as suggestions, never executed.

The first-and-last rule

Run it first (right after a fresh install, before adding apps) and last (after your full setup and cleanup). Compare the two reports to see exactly what you added and whether anything unwanted came back.

Safety

Read-only: no pacman -R, no rm, no service changes. It only prints commands you could run — you stay in control. Removal is a separate, opt-in step.

Known limitation

The current uploaded version matches pacman -Qs output with grep "^pkg ", but those lines start with local/, so installed packages can be missed. A corrected copy lives in omababy. This page and the other docs explain the script; the script itself is unchanged here.

Companion: actually removing bloat

Detection is step one. For safe, reversible cleanup with a guard list and confirmation prompts, see debloat-omarchy.sh in omababy. Nothing runs freely — you always choose.
